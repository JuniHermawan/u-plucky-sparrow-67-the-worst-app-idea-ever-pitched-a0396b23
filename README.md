SockMatch — the worst app idea ever pitched, in one sentence: an app that photographs your laundry pile, declares which socks are now legally single, and pairs the survivors with new partners at a supervised speed-dating event. We're raising $4M to end sock loneliness.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic, standard library only, and writes the single-sentence pitch (206 characters) to `/output/entry.txt`.
